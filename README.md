Hubble Network is a Seattle-based IoT connectivity company, founded in 2021 by Alex Haro (Life360) and Ben Wild (Amazon Sidewalk), building a dual-stack global network that any standard Bluetooth Low Energy 5.0+ chip can reach with no modem and no custom radio hardware. The Terrestrial Network aggregates 100M+ BLE scanning gateways across 2,500+ cities, and a low-Earth-orbit Satellite Network is rolling out on the same silicon. The platform is built API-first: the Hubble Platform (Cloud) API at api.hubble.com covers device registration and lifecycle, encrypted packet retrieval and streaming, packet webhooks, platform metrics, organization and user administration, scoped API keys, and billing. Hubble publishes a public OpenAPI definition, an open-source Device SDK in C, a Python SDK/CLI, gateway SDKs for Linux, iOS and Android, and an official Claude Code agent skill for its Cloud API.
